# Usability test: plugin navigation and Contacts happy path

Participants should be able to:
1. Identify the active workspace from the workspace switcher.
2. Discover that Contacts is unavailable before plugin enablement.
3. Enable Contacts from plugin settings without seeing implementation terms such as tenant or manifest.
4. See the Contacts navigation item appear after enablement.
5. Create a person and understand validation feedback when a required name or valid email is missing.
6. Switch workspaces and understand that plugin availability is workspace-specific.

Pass criteria: 4 of 5 participants complete steps 1-5 without facilitator intervention; all participants can explain workspace-specific plugin enablement after step 6.
