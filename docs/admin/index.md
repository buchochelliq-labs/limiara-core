# Administration guide

The production administration experience is planned. This page is an honest index of the contracts being built; it is not a claim that a complete administrator interface ships today.

## Planned responsibilities

- workspace membership, roles, and permissions;
- plugin discovery, enablement, disablement, upgrades, and failure recovery;
- tenant-defined fields and metadata-driven page customisation;
- publication, history, rollback, and conflict inspection for tenant metadata;
- retention, privacy, backup, restore, and audit operations.

Current design references include the [customisation model](../architecture/customisation-model.md), [metadata resolution](../architecture/metadata-resolution.md), [plugin supply-chain controls](../plugins/supply-chain.md), and [GDPR/privacy controls](../security/gdpr-and-privacy.md). Consult the [roadmap](../roadmap/README.md) before relying on any described operation.
